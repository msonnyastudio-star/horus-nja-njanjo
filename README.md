# Export du site Horus Nja Njanjo

Ce ZIP contient une version statique exploitable du site ainsi que les contenus et visuels récupérés.

Fichiers principaux :
- index.html
- style.css
- script.js
- assets/
- site-content.txt
- metadata.json

Utilisation :
1. Dézippez le dossier.
2. Ouvrez index.html dans un navigateur.
3. Vous pouvez ensuite modifier le code dans VS Code, Codex, Claude Code, etc.
4. Le dossier peut être déployé comme site statique sur Netlify, Firebase Hosting ou Vercel.

Important :
Le Site ChatGPT d'origine est exposé dans la bibliothèque comme une projection de Site, pas comme un dépôt de code téléchargeable. Cette archive est donc une reconstruction statique fidèle à partir du contenu accessible et des visuels Horus retrouvés dans la bibliothèque, et non un export bit-à-bit du code interne du générateur de Site.
